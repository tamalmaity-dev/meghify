# v0.9.4 - Automatic ACME email, WWW redirects and TLS inspection

**Released:** 2026-10-22 - **Tag:** `v0.9.4`

This release makes trusted HTTPS work without editing the environment after
signup, brings the Domains dialog closer to the Coolify layout, and adds a
live certificate inspector.

## Let's Encrypt email from the first admin

`grep ACME_EMAIL /opt/meghify/.env` returning nothing was expected on older
installs: the installer never wrote the key. The effective address was
therefore empty and Traefik had no ACME resolver.

The panel now resolves the ACME address like this:

1. use `ACME_EMAIL` when it is set in the environment;
2. otherwise use the first admin account's signup email.

The proxy records the effective address and is recreated when it changes. A
panel restart after `meghify update` is enough; no application redeploy is
needed. The Domains card shows the address currently in use.

The installer now writes an empty `ACME_EMAIL=` key on fresh installs and adds
it to older `.env` files without overwriting an existing value.

## Domains dialog

The add/edit dialog now exposes:

- **Search engine indexing** - Indexable or No index. No index generates a real
  `X-Robots-Tag: none` response header.
- **WWW redirect** - No redirect, redirect to `www`, or redirect to non-www.
  Both hostnames are included in the router and certificate request; the
  alternate host permanently redirects to the canonical one. Both names need
  DNS records.
- **HTTP -> HTTPS** - per-domain redirect control.
- **Regenerate hostname** - creates a fresh random `sslip.io` name for
  automatic domains. Saving it also updates the application's primary link.

Saving a changed hostname now keeps the application's primary address in sync,
and overlapping apex/`www` hostnames owned by another application are rejected
before the route is written.

## TLS certificate inspector

Each domain row has a shield action. It connects to the host on port 443 and
opens a certificate panel with:

- issuer and subject;
- validity dates and DNS names;
- whether the hostname/dates are valid;
- whether the certificate chain is trusted.

This distinguishes a real Let's Encrypt certificate from
`TRAEFIK DEFAULT CERT` without reading `acme.json` by hand.

## Migration and compatibility

- Adds the `www_redirect` column to `domains`.
- Existing domains keep the historical exact-host route (no redirect).
- Resource Guard, SQLite, cleanup schedules, terminal access and existing
  routing files are unchanged.

## Update

```bash
meghify update
meghify restart
```

Then open the domain and wait up to a minute for Let's Encrypt issuance. DNS
must point at the server and ports 80/443 must be reachable.

## Validation

- `go test -count=1 ./...`
- `go vet ./...`
- `go build -tags web_assets ./...`
- `npm run build`

Docker runtime validation (proxy recreation, ACME issuance, and live WWW
redirects) still requires a Docker-capable host.
