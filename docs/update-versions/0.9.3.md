# v0.9.3 - TLS proxy recreation and domain links

**Released:** 2026-10-22 - **Tag:** `v0.9.3`

This patch fixes HTTPS domains that redirected from HTTP but answered
`404 page not found` with `TRAEFIK DEFAULT CERT`, and adds a domain switcher to
the application header.

## HTTPS after adding ACME_EMAIL

The certificate resolver is part of the proxy container's command. A proxy
created before `ACME_EMAIL` was configured did not have the resolver. The panel
still generated HTTPS routers that named `letsencrypt`, so Traefik dropped
those routers:

- HTTP -> HTTPS redirect worked;
- HTTPS answered `404 page not found`;
- the browser received Traefik's fallback certificate.

`ensureProxy` now records the current ACME address on the proxy and recreates
the proxy when it changes. A panel restart after editing `ACME_EMAIL` is enough
to install the resolver. Certificates are then requested automatically once DNS
matches and ports 80/443 are reachable; the `traefik-letsencrypt` volume keeps
existing certificates across the recreation.

TLS routers without a resolver now emit an explicit empty TLS configuration
(`tls: {}`) instead of a YAML null. This keeps HTTPS routing working with
Traefik's fallback certificate on installs that deliberately leave
`ACME_EMAIL` empty.

## Application header domain switcher

The application header previously showed only the primary domain. When more
than one domain is attached, the primary domain is now a dropdown that lists
every attached domain with its correct HTTP/HTTPS scheme and path. The dropdown
also links back to **Domains** for admins.

## Help updates

The Help page now covers:

- HTTPS certificate requirements and the `TRAEFIK DEFAULT CERT` symptom;
- the domain **Search indexing** checkbox, which adds the real
  `X-Robots-Tag: none` response header when unchecked;
- the fact that adding a domain is hot-applied and does **not** require a
  redeploy. A redeploy is only needed after changing the container port, image
  or runtime environment.

## Also fixed

- Routing files now receive a fresh modification time on every upload. Traefik
  still hot-reloads through its file-provider watcher, but tools that inspect
  the routing volume no longer see 1970 timestamps.
