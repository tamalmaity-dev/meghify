# v0.4.0 — application workspace: networking, runtime, terminal, danger zone

**Released:** 2026-10-17 · **Commit:** [`3b58855`](https://github.com/tamalmaity-dev/meghify/commit/3b58855) · **Tag:** `v0.4.0`

The application page becomes a full workspace around the deployment pipeline —
everything Coolify's General/Advanced tabs expose that has a real counterpart
here: published ports, container limits, lifecycle hooks, an inline terminal
and application deletion.

## Update

```bash
meghify update
```

or re-run the installer. Migration `004_app_runtime` is additive: it adds the
runtime columns to applications and defaults them to "engine default".

## What changed

### Networking

- **Container port** — the port the proxy routes to, editable.
- **Port mappings** — publish container ports on the host, e.g. `8085:3000`
  (comma separated). Deployments bind them on the host; a mapped port is
  reachable even without a domain.
- **Container labels** — the proxy wiring the next deployment attaches, shown
  read-only (`/applications/{id}/labels`).

### Runtime

- **CPU and memory ceilings** per container (`1.5`, `512m`, `2g`).
- **Pre-deployment command** — runs inside the previous container before the
  swap (e.g. `php artisan down`).
- **Post-deployment command** — runs inside the new container once it is live
  (e.g. `php artisan migrate --force`).
- A failing hook fails the deployment and says so in the log.

### Terminal

The container shell moves from a modal into a **Terminal** section (the
header icon jumps to it), with the same resize-aware terminal the server pages
use.

### Danger zone

**Delete application** stops and removes the container, then deletes the
application with its configuration, domains, variables and history. Volumes
and stored data stay on disk.

### Release pipeline

- An application that publishes host ports now releases them by retiring the
  old container just before the replacement starts (host ports cannot be
  bound twice); everything else keeps the zero-downtime swap.
- The **Access** card on General shows the port mappings and links straight to
  the Networking section.
