# v0.9.2 - Port binding help in the panel

**Released:** 2026-10-22 - **Tag:** `v0.9.2`

This patch adds an in-panel **Help** page for the networking model, linked from
the application's Networking card.

## What is new

- A **Help → Ports & networking** page explains container ports, host/VPS
  ports, domain routing and port mappings.
- Diagrams show two applications safely sharing container port `3000`, and how
  direct VPS access maps different host ports onto the same container port.
- A field reference covers **Container port**, **Port mappings**, **Domains →
  Internal port** and the automatic `PORT` environment value.
- A step-by-step **Bad Gateway** checklist points to the actual listener in
  Runtime logs, the `0.0.0.0` bind requirement, explicit `PORT` conflicts and
  inherited domain ports.
- Quick-answer cards and copy-ready `docker ps` / `ss` checks make the page
  useful without leaving the panel.
